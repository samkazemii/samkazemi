V13.1 Conversation + Persian Voice Fix

Changes:
- Normal conversational replies for greetings, small talk, emotions and follow-up messages.
- Shorter, human-style replies instead of repeating the same checklist.
- Persian speech synthesis selects fa-IR/fa system voices when the device provides one.
- Persian speech rate adjusted for clarity.
- Voice mode cycles through Listening, Thinking and Speaking.
- AI name shortened to SK AI.

Important browser limitation:
Speech output uses the voices installed by the operating system/browser. If no Persian voice exists on that device, the written Persian answer still works but the browser cannot invent a Persian voice. Android Chrome with Google Persian speech services usually gives the best result. iOS voice availability depends on installed system voices.
